# Organization

Orden de tareas facultativas.

## Prioridades

App de una sola pantalla para ordenar lo que tenés que estudiar. Cinco bloques
de colores, uno arriba del otro: el de arriba es lo primero que hacés hoy.

- **Nombre y tarea**: cada bloque tiene un campo para la materia (ej. Historia)
  y otro para lo que hay que hacer (ej. "1 hora de estudio", "TP práctico").
- **Reordenar**: arrastrá desde el ⠿ (funciona con mouse y con el dedo) o usá
  las flechas ▲ ▼.
- **Colores**: el botón ● abre la paleta. Si elegís un color que ya usa otro
  bloque, los dos se intercambian.
- **Agregar / quitar**: podés sumar bloques con "+ Agregar bloque" o borrarlos
  con ✕. "Vaciar" vuelve a los 5 iniciales.
- Todo se guarda automáticamente en el navegador del dispositivo.

### Cómo usarla

Abrí `index.html` en cualquier navegador (celular o computadora). No necesita
instalación, servidor ni conexión a internet.

En el celular conviene agregarla a la pantalla de inicio ("Añadir a pantalla
principal" en el menú del navegador) para abrirla como una app.
